# B站逐字稿

这是基于 MIT 许可的 YouTube Digest 改造的个人 Chrome 扩展。它直接读取 B 站普通视频页面中已有的字幕轨道，在 Chrome 侧边栏生成带时间戳的逐字稿。

## 功能

- 优先选择简体中文字幕，其次选择其他中文或可用字幕。
- 将零碎字幕合并成连续段落，并去除同一时间点的重复字幕。
- 只读取当前激活的视频标签页，并在侧边栏显示 BV 号供核对。
- 完全按需运行：打开视频或切换标签页时不读取字幕，只有点击“生成当前视频逐字稿”才请求字幕。
- 点击任意字幕行跳转到对应播放位置。
- 一键复制带时间戳的逐字稿。
- 导出 UTF-8 编码的 TXT 文件。
- 支持多 P 视频，按当前 URL 的 `p` 参数读取对应分 P。
- 不需要 Supadata 或 DeepSeek API Key，不产生这两项 API 费用。

## 安装

1. 在 Chrome 地址栏打开 `chrome://extensions`。
2. 打开右上角“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择这个项目文件夹（包含 `manifest.json` 的目录）。
5. 打开一个 `https://www.bilibili.com/video/BV...` 视频页面。
6. 点击扩展图标打开侧边栏，再点击“生成当前视频逐字稿”。

如果点击扩展图标后没有打开侧边栏，请先在 `chrome://extensions` 中点击本扩展的“重新加载”，再回到视频页面刷新一次。

更新代码后，在 `chrome://extensions` 中点击扩展卡片上的“重新加载”，并刷新已打开的 B 站视频页面。

## 限制

- 只读取视频已有的字幕轨道；弹幕不是字幕。
- 如果播放器的 CC 菜单没有字幕，本扩展不会下载音频或进行语音识别。
- 直播、番剧专用播放页、动态内嵌视频和受限视频暂未适配。
- B 站接口或页面结构变化后，可能需要更新扩展。

## 隐私

字幕请求直接发送到 B 站官方域名。扩展没有开发者服务器、分析统计或第三方 AI 请求，也不会保存 API Key。
